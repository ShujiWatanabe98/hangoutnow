# Initial Operation Model

## Goal

20人規模のクローズドテストを、顧客満足と安全を保ちながら最小費用で実施できる形にする。公開運用の予算ではなく、M0段階の仮試算です。

## Supply design

- 対象セル: 新宿駅周辺約2km、金曜・土曜18:00–22:00、カフェ・早めの食事
- テスト参加候補: 20人
- 初期ホスト候補: 5人
- 1開催: ホスト1人 + 参加者1〜3人
- 1日当たりの募集: 4件を仮置き
- 2日間の募集: 8件
- 集合場所: 駅構内ではなく、名称が明確な公共店舗または人目のある公共施設

この件数は需要を証明する値ではありません。ホスト1人当たり1〜2件で主要導線を反復検証するためのテスト設計です。

## Cost scenarios

金額は市場価格ではなく、意思決定用の上限仮説です。外部支出は人間承認が必要です。

| Item | Lean | Supported | Rule |
|---|---:|---:|---|
| Interview incentives, 20 people | ¥0 | ¥20,000 | 無償協力または1人¥1,000。採用率への影響を記録 |
| Host support, 5 people | ¥0 | ¥10,000 | 1人上限¥2,000。参加者を装う報酬は禁止 |
| Venue | ¥0 | ¥0 | 各自の飲食費のみ。運営が店舗貸切をしない |
| Ads | ¥0 | ¥0 | M0では実施しない |
| Tools | ¥0 | ¥0 | 既存リポジトリと承認済みツールを優先 |
| Total external cash | ¥0 | ¥30,000 | 人件費を除く |

## Human workload estimate

| Work | One-time | Per test day | Reduction method |
|---|---:|---:|---|
| Participant scheduling and consent | 3–5h | 0.5h | 定型フォームと一括日程候補 |
| Host onboarding | 2h | 0.5h | 1ページ手順書、15分合同説明 |
| Supply check | 1h | 0.5h | 時間帯別チェックリスト |
| Support and safety standby | 1h setup | 4h | テスト時間帯を限定、緊急/通常を分類 |
| Interview and synthesis | 8–12h | — | 共通質問と符号化表 |

安全対応の待機時間は、費用削減対象として省略しません。対象時間帯を4時間に限定して負荷を抑えます。

## Customer satisfaction model

### Measures

- Hangout終了直後の5段階満足度
- 「同じ条件なら再利用したいか」
- 参加前の不安が解消されたか
- 募集発見から承認までの分かりやすさ
- サポート問い合わせの初回解決
- 無断欠席、キャンセル、通報

回答が5件未満の小さな属性内訳は共有せず、自由記述は個人情報を削除して要約します。

### Stop conditions

- 重大な安全インシデント1件
- 承認前の正確な位置情報露出1件
- 未成年参加の疑い
- 通報やブロックが機能しない
- 運営がテスト時間帯に安全問い合わせへ対応できない

## Low-cost operation rules

- 広告より、同意済みテスターと初期ホストの確保を先にする
- エリアと時間帯を限定し、サポート待機時間を集中する
- FAQ、返信テンプレート、ホスト手順書で反復質問を減らす
- 同じ問題が3回以上起きたら、人手継続ではなくagent_developmentへ改善要求を出す
- インストール報酬を使わず、安全に完了した検証参加だけを必要に応じて補助する
- 無料であることより、費用当たりのActivation、3H Match、満足度で判断する

## Operation request to agent_development

- 管理画面に通報状態、担当、対応履歴を持たせる
- ホストに申請未処理と開始前リマインダーを出す
- キャンセル、無断欠席、参加完了を構造化して記録する
- よくある問い合わせを個人情報なしで分類できるようにする
- 正確な位置や私信を通知ロック画面へ既定表示しない

## Operation response to agent_marketing

- 新宿仮説はテスト可能だが、募集8件を確保する前の送客は不可
- 「孤独」を弱みとして訴求せず、「今から活動」を中心にする
- 短尺動画や有料広告は、クローズドテストで安全と成立を確認した後に評価する
