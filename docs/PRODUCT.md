# Product

Hangout Now connects nearby adults through an activity they want to do soon.

The MVP journey is: register → create or discover a Hangout → request to join → host approval → chat → meet → mutual feedback.

The defining constraint is immediacy. Hangouts start in 30 minutes, 1 hour, or 3 hours. The primary KPI is the percentage matched within three hours (`3H Match Rate`). Users under 18 are outside the MVP scope.
