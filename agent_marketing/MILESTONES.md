# Marketing Milestones

## M0: Research Foundation

**Goal:** 調査で決めること、対象範囲、証拠基準を定義する。

### Agent actions

- 既存のPRODUCT、SECURITY、デモ、agent_operation資料を確認する
- 意思決定事項と未確認仮説を一覧化する
- 地域、年齢範囲、利用場面、調査期間を定義する
- インタビューと二次調査の計画を作る

### Exit criteria

- 調査目的、対象、除外対象、期限が承認されている
- 事実、推論、仮説、unknownを区別する形式がある

## M1: Market and Alternative Research

**Goal:** 市場背景、代替手段、競争環境を理解する。

### Agent actions

- 対象地域の人口、移動、余暇、単独行動に関する資料を調査する
- 直接競合、間接競合、非消費を比較する
- 競合の対象、価値提案、主導線、安全策、価格、レビュー傾向を調べる
- TAM、SAM、初期SOMを前提付きで推計する
- 規制、ストア規約、季節性、文化的障壁を整理する

### Exit criteria

- 主要主張に出典と調査日がある
- 現在の代替手段と未充足ニーズが区別されている
- 初期SOMが地域・時間・活動の供給制約を反映している

## M2: Customer Discovery

**Goal:** 実際の行動と利用障壁を一次調査で確認する。

### Agent actions

- 候補セグメントごとにインタビュー対象を募集する計画を作る
- 成人10〜20人以上へ直近行動を中心に聞く
- 利用契機、代替手段、断念理由、安全条件を符号化する
- セグメントごとの共通点と反証を整理する
- 追加調査が必要な偏りを記録する

### Exit criteria

- 同意済みの一次調査がある
- 最低10件の検証可能な回答がある
- 課題頻度と直近行動の証拠がある
- 「使いたい」という意向だけでターゲットを選んでいない

## M3: Segmentation and Target Selection

**Goal:** 最初に集中する顧客と利用セルを1つ選ぶ。

### Agent actions

- Situation、Job、Urgency、Location、Activityでセグメント化する
- Target Selection Scoreで候補を比較する
- 安全性と供給成立性の低い候補を除外する
- 初期ターゲット、予備ターゲット、対象外を提案する
- 選択を反証するテストを作る

### Exit criteria

- 初期ターゲットが1つに絞られている
- エリア、時間帯、活動、利用契機が具体的
- 選択根拠、反証、unknownが明記されている
- agent_developmentとagent_operationが利用できる形で引き渡されている

## M4: Persona and Jobs to Be Done

**Goal:** ターゲットの意思決定を、実装と訴求に使える形にする。

### Agent actions

- 行動ベースの主要ペルソナを1〜2件作る
- JTBD、利用前後の状態、トリガー、障壁、代替手段を記述する
- 信頼を得る情報と離脱させる表現を整理する
- 調査根拠と未検証仮説を各項目へ付ける
- シナリオと主要導線の受入条件へ変換する

### Exit criteria

- ペルソナが実在個人やステレオタイプではない
- 各重要項目に根拠または仮説ラベルがある
- 開発優先順位とマーケティング表現の両方に利用できる

## M5: Positioning and Message Validation

**Goal:** ターゲットが短時間で理解し、信頼できる表現を見つける。

### Agent actions

- Category、Alternative、Unique Value、Proofを整理する
- 主価値1案、代替案2〜3案を作る
- ストア冒頭文、ランディングページ、短尺動画の仮説を作る
- 理解度、関連性、信頼、安全性を定性・定量で検証する
- 性的出会いや安全保証と誤解される表現を除く

### Exit criteria

- 対象ユーザーが価値を自分の言葉で説明できる
- 検証済み主メッセージと禁止表現がある
- クリエイティブからアプリ内体験まで一貫している

## M6: Pre-Launch Market Validation

**Goal:** 大規模公開前に、需要と供給の成立可能性を検証する。

### Agent actions

- 待機リスト、説明ページ、初期ホスト募集の実験を設計する
- チャネル別にQualified SignupとHost Intentを比較する
- ダウンロード意向ではなく、具体的な日時・活動への行動を測る
- 初期セルの供給不足と安全上の障壁をagent_operationへ渡す
- 訴求が実装済み機能と一致するかagent_developmentと確認する

### Exit criteria

- 初期セルに測定可能な需要とホスト候補がある
- 少なくとも1つ到達可能なチャネルがある
- 誇張なしに使える証拠とメッセージが揃っている

## M7: Launch Learning

**Goal:** 公開後の実行動からターゲットと訴求を更新する。

### Agent actions

- チャネル別にinstallではなくActivation、3H Match、D7を比較する
- ペルソナ想定と実ユーザー行動の差を分析する
- ストアレビュー、サポート、離脱理由を匿名化して分類する
- メッセージと実体験の不一致を発見する
- keep、change、stopをagent_operationへ提案する

### Exit criteria

- 初期コホートの行動データがある
- ターゲット、ペルソナ、ポジショニングが実データで更新されている
- 質の高いユーザーを得るチャネルが識別されている

## M8: Expansion Research

**Goal:** 隣接エリアや新セグメントへ拡大できるか検証する。

### Agent actions

- 新市場を既存市場と同じ指標で比較する
- 現地の活動密度、移動、文化、安全、到達チャネルを調査する
- 既存ペルソナを流用せず、差分を一次調査する
- 翻訳ではなくローカライズすべき要素を特定する
- 拡大、保留、撤退を証拠付きで提案する

### Exit criteria

- 新市場の供給と需要が小規模に確認されている
- 既存市場を弱めず展開できる
- 人間が次市場を承認している
