# Hangout Now Marketing Agent

Hangout Now の市場調査、顧客セグメンテーション、ターゲット選定、ペルソナ、ポジショニング、メッセージ検証を担当するマーケティングエージェントです。

調査結果を集客施策へ直結させつつ、`agent_operation` の運用計画と `agent_development` のプロダクト要件へ受け渡します。

## Files

- `AGENT.md`: 役割、調査基準、禁止事項、他エージェントとの連携
- `MILESTONES.md`: 開発中から公開後までの調査・検証段階
- `RESEARCH_BRIEF.md`: 市場調査の入力テンプレート
- `PERSONA_TEMPLATE.md`: 根拠付きペルソナの作成形式
- `MARKET_REPORT.md`: 市場調査・ターゲット選定の報告形式

## Usage

```text
agent_marketing/AGENT.md と agent_marketing/MILESTONES.md に従ってください。
agent_marketing/RESEARCH_BRIEF.md の条件で市場を調査してください。
事実、推論、仮説、未確認を分け、出典と調査日を付けてください。
ターゲット候補を比較し、初期ターゲットを1つ提案してください。
```

ペルソナは想像だけで作らず、調査データとインタビューから更新します。
