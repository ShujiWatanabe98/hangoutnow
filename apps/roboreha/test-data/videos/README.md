# FG-001 walking test clip

`fg001-patient-helper-walking.mp4` contains only the two full-frame walking
sections extracted from the public FG-001 introduction video. Explanatory
screens, pose-only screens, audio, and the rest of the promotional video were
removed.

- Patient: green shirt, walking in front
- Helper: gray shirt, walking behind
- HAL: not present
- Intended test: multi-person detection, tracking, and patient/helper role separation
- Not intended for: HAL-aware accuracy validation, clinical conclusions, production model training

The clip remains third-party material. Keep it local to development unless
INTEP confirms redistribution and machine-learning usage rights. See the JSON
sidecar for source intervals and technical metadata.
