# Pose model assets

`pose_landmarker_lite.task` is the MediaPipe Pose Landmarker Lite model used for local browser inference by RoboReha FG Lite.

- Runtime package: `@mediapipe/tasks-vision` 1.0.1
- Package license: Apache-2.0
- The model and WASM files are loaded locally; no FG001 API is called.

Review the upstream package/model terms before redistribution or public deployment.
